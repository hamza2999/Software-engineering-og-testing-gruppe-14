# Software-engineering-og-testing-gruppe-14
Gruppe 14 sin kodebase for Østfold husflidslag, det er Hamza, Magomed, Abdulahi, Jovan og Oskar som arbeider i dette repo-et

## Kjør frontend lokalt

Fra repo-roten kan du starte frontend med:

```bash
npm install --prefix Frontend
npm run dev
```

Dette kjører Vite i [Frontend](Frontend) uten at du trenger å `cd` inn i undermappen manuelt.
